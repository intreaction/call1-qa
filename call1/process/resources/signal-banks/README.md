Source: [AppTek Call-Center Dialogues](https://huggingface.co/datasets/apptek-com/apptek_callcenter_dialogues), revision `b98967d9946f7f59f58d08624a2a00fe98fe0219`. Adaptations: masking, approximately seven-second segmentation and silver signal labels. The JSON records the source call IDs, attribution and digest pinned by the retail taxonomy.

Process uses this as an example lookup bank for the retail rules demonstration. It does not contain model weights or real customer recordings. These are role-played evaluation examples; their inclusion does not establish a license or validation claim for training/fine-tuning models. Existing operator-installed banks can override this bundled resource.
