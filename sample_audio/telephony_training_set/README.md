# AppTek evaluation annotations

This directory retains Call1's reformatted transcript/turn annotations for ten role-played calls, under the same license. The full recordings and raw metadata are omitted from this source distribution. The historical directory name does not mean that these are cleared model-training data. The current upstream card specifies evaluation/analysis as intended use, not ASR or foundation-model training/fine-tuning.

The original download did not capture an upstream revision. Exact original audio hashes and dataset provenance are retained in [the provenance record](../../benchmarks/2026-09-11-dataset-provenance.json). Tests use the transcript manifest for redaction and segmentation regression checks.
